# TenantHub

TenantHub is a backend API for a multi-company application.
Each company has its own users, and users can only see their own company's data.

## Features
- Register users under a company
- Login and get a token

## Requirements
- .NET SDK

## How to run
1. Open a terminal in the project folder
2. Run:dotnet run
3. Open the link shown in the terminal, then go to `/weatherforecast` to test
